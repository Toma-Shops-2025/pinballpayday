# Pinball Payday

A high-stakes pinball game where skill equals earnings.

## Features
- Physics-based gameplay via Matter.js
- Integrated AppLovin MAX ads
- Real-time scoring and rewards
- Global Leaderboards (via Supabase)

## Getting Started
1. Install dependencies: `npm install`
2. Build the app: `npm run build`
3. Sync with Capacitor: `npx cap sync android`
4. Build AAB: `.\build-aab.ps1`
